## Project Overview

**Trabajo Final — Asignatura Inteligencia Artificial**: ML model for financial risk classification of Colombian SMEs using SIREM datasets from the Superintendencia de Sociedades.

**Scope**: Course assignment focused only on the AI/ML component. There is **no web system** — that belongs to a separate (broader) thesis project. The web prototype spec was removed.

**Train/test convention**: Models are trained on the **national dataset** (38,245 SMEs, 2016–2024). Final validation and case-study analysis is done on the **Ibagué subset** (61 SMEs identified via Cámara de Comercio cross-match). Ibagué is held out from training to avoid leakage.

## Data Architecture

### Source: SIREM Datasets (~9.17 GB total)

Four CSV files in `dataset/` (gitignored), all sharing the same 11-column **vertical/long format** (one row per concept-value pair, NOT one row per company):

| Column | Purpose |
|--------|---------|
| `NIT` | Company tax ID (may contain commas like `"900,152,104"` — must be cleaned) |
| `PUNTO_ENTRADA` | Company type: "NIIF Pymes" (SMEs, our focus) vs "NIIF Plenas" (large companies) |
| `TAXONOMIA` | Fiscal year cutoff (truncated to "Corte 202" for 2021+ — use `FECHA_CORTE` instead) |
| `CONCEPTO` | Financial account name (e.g., "Activos corrientes totales") |
| `PERIODO` | Reporting period (anomaly: NITs appear here for some 2016 cash flow rows) |
| `VALOR` | Numeric value (text in Caratula dataset) |

### The four datasets:

1. **Caratula** (2.07 GB) — Company metadata. `VALOR` mixed text/numeric.
2. **Estado de Situación Financiera** (4.10 GB) — Balance sheet. ~80 unique account concepts.
3. **Estado de Resultado Integral** (1.57 GB) — Income statement. ~23 concepts.
4. **Estado de Flujo de Efectivo** (1.43 GB) — Cash flow statement. ~101 concepts.

### Consolidated output (after notebook 02)

`data/processed/colombia_consolidado_pymes.csv` — 203,104 rows × 230 columns (2 ID + 24 metadata + 204 financial). Pivoted: one row per (NIT, año), each concept becomes a column.

### Critical data handling notes

- **Files are large**: use chunked reading (`chunksize=` in `pd.read_csv`) when memory is a concern.
- **Always use `low_memory=False`** when reading the raw CSVs.
- **Encoding (raw)**: UTF-8 for Carátula, Latin-1 for the three financial statements.
- **Encoding (consolidated)**: 105 of the 230 columns contain mojibake (`ï¿½` in place of accented vowels — `pï¿½rdida`, `operaciï¿½n`, etc.) because the ETL re-saved with mismatched encoding. **Always load the consolidated CSV via `src.etl_utils.cargar_consolidado()` or call `normalizar_columnas()` after `pd.read_csv()`** — `src/indicadores.py` assumes columns are already normalized to ASCII.
- **NIT cleanup**: SIREM stores NITs with commas (`"900,152,104"`). Strip non-numeric. Cámara de Comercio stores them with a check digit (10 digits) — drop the last digit to match SIREM (9 digits). See notebook 01 cells 26–30.
- **Pivoting**: data is vertical (concept-value rows). To analyze a company, filter by NIT and pivot CONCEPTO into columns. `aggfunc='first'` resolves the 14–18% duplicates that come from multiple `PUNTO_ENTRADA` subtypes.
- **Filter by `PUNTO_ENTRADA`** containing "Pymes" to isolate SME data.
- **Year extraction**: use `FECHA_CORTE` (regex `[0-9]{4}`), not `TAXONOMIA` (truncated for 2021+).
- **Period filter**: remove rows where `PERIODO` contains "Anterior" or matches a year that does not equal `ANIO` — see `filtrar_periodo()` in notebook 02 cell 5.

### Key financial concepts (column names in the consolidated CSV)

These are the exact strings used as keys in `src/indicadores.py`:

**From Situación Financiera**: `Activos corrientes totales`, `Pasivos corrientes totales`, `Total pasivos`, `Total de activos`, `Patrimonio total`, `Inventarios corrientes`, `Efectivo y equivalentes al efectivo`, `Cuentas comerciales por cobrar y otras cuentas por cobrar corrientes`, `Ganancias acumuladas`.

**From Resultado Integral**: `Ingresos de actividades ordinarias`, `Costo de ventas`, `Ganancia bruta`, `Ganancia (perdida) por actividades de operacion`, `Costos financieros`, `Ganancia (perdida)`.
